# Study Desk Lite

[Open the demo](https://matt-c-portfolio.github.io/study-desk-lite/) — no installation needed.

A DATA 785 project comparing local DeepSeek models with OpenAI for lecture study
guides and question answering. Includes ten lectures and their saved results.

## Run locally

Follow the [Windows setup instructions](docs/SETUP.md) to load the included dataset
and run the app on your computer.
